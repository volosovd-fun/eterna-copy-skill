# Як пише Eterna — скіл копірайту для підрядників

Правила сильного тексту для всіх, хто пише від імені Eterna Sports: реклама Meta і Google, пости, описи товарів, листи, відповіді в директі. Метод «пиши, скорочуй» (інформаційний стиль), накладений на Tone of Voice бренду і факти сайту.

**Версія:** 1.0 · 11.09.2026 · зміни — у `CHANGELOG.md`.

## Що в пакеті

| Файл | Роль |
|---|---|
| `SKILL.md` | Конституція: порядок роботи, 10 правил, стоп-лист, чеклист із 13 питань, межі. Читати першим, вантажити в system prompt. |
| `Eterna_Sports_Tone_of_Voice.md` | Голос бренду. Теж у system prompt. |
| `references/facts.md` | Єдине джерело фактів: каталог, гравіювання, коробка, доставка, повернення, гарантія, бренд. |
| `references/glossary.md` | Термінологія падел EN ↔ UA: як на сайті, як у конкурентів, що пишемо, чого не пишемо. |
| `references/formats.md` | Каркаси й ліміти: Meta, Google RSA, Instagram, email, сторінка товару, директ. |
| `references/before-after.md` | Реальні оголошення, розібрані за правилами і переписані. Найшвидший спосіб зрозуміти різницю. |
| `references/techniques.md` | Каталог прийомів інформаційного стилю з прикладами під Eterna. Довідник. |

## Як підключити до свого агента

**Claude Code.** Скопіюйте папку в `.claude/skills/eterna-copy/` свого проєкту (або `~/.claude/skills/` для всіх проєктів). Скіл підхопиться автоматично; викликається `/eterna-copy` або сам, коли пишете тексти для Eterna.

**Claude.ai (Projects).** Створіть проєкт «Eterna Copy». У «Instructions» вставте текст із розділу нижче. У «Project knowledge» завантажте всі сім файлів.

**ChatGPT (Projects або Custom GPT).** Те саме: текст нижче — в Instructions, сім файлів — у Files / Knowledge.

**Cursor, Codex, інші агенти з файлами правил.** Покладіть папку в репозиторій і додайте в правила агента рядок: «Перед будь-яким текстом для Eterna виконуй `eterna-copy/SKILL.md`».

## Текст для Instructions / system prompt

> Ти пишеш тексти для бренду Eterna Sports. Перед кожним текстом виконуй `SKILL.md`, розділи 0 → 1 → 4, і дотримуйся `Eterna_Sports_Tone_of_Voice.md`. Факти бери тільки з `references/facts.md`; терміни — з `references/glossary.md`. Якщо факту немає у файлі — не вигадуй, а познач `[перевірити]`. Здавай кожен текст у форматі: (1) кому і яка користь одним рядком, (2) сам текст, (3) заповнений чеклист із розділу 4 SKILL.md з відповідями так/ні. Рядок платної реклами без конкретного атрибута товару переписуй до здачі.

## Як бренд приймає тексти

1. Чеклист `SKILL.md` §4 — 13 «так». Одне «ні» повертає текст із номером правила.
2. Кожен факт звіряється з `references/facts.md` і живою сторінкою сайту.
3. Тест «замаж бренд»: якщо текст пасує будь-якому виробнику ракеток, він повертається.
4. Польська, італійська, німецька, французька — вичитка носієм до публікації.
